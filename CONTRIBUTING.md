# Contributing

The Hootask SDK is built by the Hootask team. We don't accept pull requests from
outside the team; any we receive will be closed.

Issues are welcome:

- **Bug report**: something doesn't work as documented
- **Feature request**: something the SDK should do
- **Question**: how to do something with the SDK

[Open an issue](https://github.com/RestfullyCare/hootask/issues/new/choose).

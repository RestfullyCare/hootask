:::caution[Pre-release]
The SDK has no public API yet.
:::

| Package          | Use it for                      |
| ---------------- | ------------------------------- |
| `@hootask/react` | React apps                      |
| `@hootask/js`    | Anything else; headless, no DOM |

## Install

```bash
npm install @hootask/react   # React
npm install @hootask/js      # anything else
```

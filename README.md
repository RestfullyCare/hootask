# Hootask SDK

Render Hootask forms in your own UI.

| Package          | What                                   |
| ---------------- | -------------------------------------- |
| `@hootask/js`    | Headless, framework-agnostic core      |
| `@hootask/react` | React bindings, built on `@hootask/js` |

> Pre-release: no public API yet.

## Install

```bash
npm install @hootask/react   # React
npm install @hootask/js      # anything else
```
